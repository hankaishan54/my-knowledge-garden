# K073 二次型的几何应用

> 线代 · 二次型 · 真题 2 题（数一 2 / 数二 0 / 数三 0）

## 核心结论
- 二次型对应二次曲面/曲线：标准形系数决定类型（椭圆、双曲、抛物）。
- 判断 $f=1$ 的形状：全部系数 $>0$ 为椭球（椭圆）；有正有负为双曲面（双曲线）；含零系数为柱面。
- 主轴方向即特征向量方向，半轴长为 $\frac{1}{\sqrt{\lambda_i}}$。
- 这类题本质是"正交变换 + 看特征值符号"，属低频考点（真题仅 2 题）。

## 关键公式
$$\frac{y_1^2}{\lambda_1}+\frac{y_2^2}{\lambda_2}=1\ \Rightarrow\ \text{半轴}\ \frac{1}{\sqrt{\lambda_i}}$$

## 典型例题
**例** 说明 $2x^{2}+3y^{2}+2\sqrt2\,xy=1$ 表示的曲线类型。

**解** $A=\begin{pmatrix}2&\sqrt2\\\sqrt2&3\end{pmatrix}$，特征值 $1,4$（均正），标准形 $y_1^{2}+4y_2^{2}=1$，为椭圆。

## 易错点
- 忘记交叉项系数要除以 $2$ 才是矩阵元素（$2\sqrt2xy$ 对应 $a_{12}=\sqrt2$）。
- 把特征值直接当半轴长。
- 只算特征值符号，不判断是否退化（有零特征值时是抛物线型）。
