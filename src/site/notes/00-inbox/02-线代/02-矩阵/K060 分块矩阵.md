# K060 分块矩阵

> 线代 · 矩阵 · 真题 1 题（数一 1 / 数二 0 / 数三 0）

## 核心结论
- 分块矩阵的乘法要求"块尺寸匹配"，按块运算规则同普通矩阵。
- 分块对角：$\begin{pmatrix}A&O\\O&B\end{pmatrix}^{n}=\begin{pmatrix}A^{n}&O\\O&B^{n}\end{pmatrix}$，行列式为 $|A||B|$，可逆时逆为分块对角之逆。
- 分块三角 $\begin{pmatrix}A&C\\O&B\end{pmatrix}$ 的行列式 $=|A||B|$。
- "箭头形"矩阵常用分块 + 初等变换处理。
- 抽象矩阵题的常规套路：分块、凑 $E$、用 $AA^{*}=|A|E$。

## 关键公式
$$\begin{vmatrix}A&C\\O&B\end{vmatrix}=|A||B|,\qquad \begin{pmatrix}A&O\\O&B\end{pmatrix}^{-1}=\begin{pmatrix}A^{-1}&O\\O&B^{-1}\end{pmatrix}$$

## 典型例题
**例** 设 $A=\begin{pmatrix}O&E\\E&O\end{pmatrix}$（$E$ 为 $n$ 阶），求 $A^{2}$。

**解** 按块乘：$A^{2}=\begin{pmatrix}O&E\\E&O\end{pmatrix}\begin{pmatrix}O&E\\E&O\end{pmatrix}=\begin{pmatrix}E&O\\O&E\end{pmatrix}=E_{2n}$。

## 易错点
- 分块乘法时把块的位置乘反（左侧的行块配右侧的列块）。
- 分块矩阵求逆直接对每块求逆而不检查是否为对角块。
- 忘记分块三角行列式为零块那一侧才成立。
