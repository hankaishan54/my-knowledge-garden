# K092 估计量的评价

> 概率 · 数理统计 · 真题 20 题（数一 10 / 数二 0 / 数三 10）

## 核心结论
- 无偏性：$E\hat\theta=\theta$。样本均值、样本方差（$n-1$ 分母）都是无偏的；$\frac{1}{n}\sum(X_i-\bar X)^{2}$ 有偏。
- 有效性：两个无偏估计中方差小者更有效。
- 一致性（相合）：$\hat\theta\xrightarrow{P}\theta$。
- 常用修正：$S^{2}$ 的分母 $n-1$ 就是为无偏而设。
- 判断"哪个更有效"：算方差比，方差小的优。

## 关键公式
$$E\hat\theta=\theta\ (\text{无偏}),\qquad D\hat\theta_1<D\hat\theta_2\ (\theta_1\ \text{更有效})$$

## 典型例题
**例** 设 $X_1,X_2$ 是 $\mu$ 的样本，比较 $\hat\mu_1=\frac{X_1+X_2}{2}$ 与 $\hat\mu_2=\frac{X_1+2X_2}{3}$ 的有效性。

**解** 二者都无偏；$D\hat\mu_1=\frac{\sigma^{2}}{2}$，$D\hat\mu_2=\frac{5\sigma^{2}}{9}$，前者更小，故 $\hat\mu_1$ 更有效。

## 易错点
- 用 $n$ 分母的样本方差说"无偏"。
- 比较有效性时只看一个估计的方差，不与另一个比。
- 混淆"无偏"与"一致"（无偏不保证一致）。
