# K089 统计量与抽样分布

> 概率 · 数理统计 · 真题 20 题（数一 8 / 数二 0 / 数三 12）

## 核心结论
- 样本均值 $\bar X=\frac{1}{n}\sum X_i$，$E\bar X=\mu$，$D\bar X=\frac{\sigma^{2}}{n}$。
- 样本方差 $S^{2}=\frac{1}{n-1}\sum(X_i-\bar X)^{2}$，$ES^{2}=\sigma^{2}$（分母是 $n-1$）。
- 正态总体三大分布：$\frac{(n-1)S^{2}}{\sigma^{2}}\sim\chi^{2}(n-1)$；$\frac{\bar X-\mu}{S/\sqrt n}\sim t(n-1)$；$\frac{\bar X-\mu}{\sigma/\sqrt n}\sim N(0,1)$。
- $F$ 分布用于两总体方差比：$\frac{S_1^{2}/\sigma_1^{2}}{S_2^{2}/\sigma_2^{2}}\sim F(n_1-1,n_2-1)$。
- $\chi^{2}$ 分布可加：独立时自由度相加。

## 关键公式
$$\frac{(n-1)S^2}{\sigma^2}\sim\chi^2(n-1),\qquad \frac{\bar X-\mu}{S/\sqrt n}\sim t(n-1)$$

## 典型例题
**例** 从 $N(\mu,\sigma^{2})$ 中取容量 $16$ 的样本，$S^{2}=4$，求 $P(\sigma^{2}>8)$ 的表达式。

**解** $\frac{15\times4}{\sigma^{2}}\sim\chi^{2}(15)$，$P(\sigma^{2}>8)=P\!\left(\chi^{2}(15)<\frac{60}{8}=7.5\right)$。

## 易错点
- 样本方差分母写成 $n$（导致 $ES^{2}\ne\sigma^{2}$）。
- $t$ 分布与 $N(0,1)$ 混用（$\sigma$ 未知时用 $S$）。
- 自由度写成 $n$ 而非 $n-1$。
