# K087 大数定律

> 概率 · 大数定律与中心极限定理 · 真题 6 题（数一 2 / 数二 0 / 数三 4）

## 核心结论
- **切比雪夫大数定律**：独立同分布（方差存在）时，样本均值依概率收敛于 $EX$。这是"频率稳定于概率"的理论依据。
- **辛钦大数定律**：独立同分布、期望存在即可，不要求方差。
- **伯努利大数定律**：频率 $\frac{\mu_n}{n}$ 依概率收敛于 $p$。
- 应用：用切比雪夫不等式估计概率 $P(|X-EX|\ge\varepsilon)\le\frac{DX}{\varepsilon^{2}}$。

## 关键公式
$$P\bigl(|X-EX|\ge\varepsilon\bigr)\le\frac{DX}{\varepsilon^{2}},\qquad \bar X\xrightarrow{P}EX$$

## 典型例题
**例** 设 $DX=1$，用切比雪夫不等式估计 $P(|X-EX|<3)$ 的下界。

**解** $P(|X-EX|\ge3)\le\frac{1}{9}$，故 $P(|X-EX|<3)\ge\frac{8}{9}$。

## 易错点
- 切比雪夫不等式方向记反（是上界不是下界，求"至少"要取 $1-$）。
- 混淆大数定律（依概率收敛）与中心极限定理（依分布收敛）。
- 忽略"独立同分布"前提。
