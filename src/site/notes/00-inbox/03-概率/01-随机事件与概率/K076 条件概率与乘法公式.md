# K076 条件概率与乘法公式

> 概率 · 随机事件与概率 · 真题 22 题（数一 8 / 数二 0 / 数三 14）

## 核心结论
- 条件概率：$P(B|A)=\dfrac{P(AB)}{P(A)}\ (P(A)>0)$；条件概率本身也是概率，满足三条公理。
- 乘法公式：$P(AB)=P(A)P(B|A)=P(B)P(A|B)$；多事件链式相乘。
- $P(B|A)+P(\bar B|A)=1$，但 $P(B|A)+P(B|\bar A)$ 一般不为 $1$。
- 条件概率与"缩减样本空间"等价：在 $A$ 发生的范围内重新算比例。

## 关键公式
$$P(B|A)=\frac{P(AB)}{P(A)},\qquad P(ABC)=P(A)P(B|A)P(C|AB)$$

## 典型例题
**例** 袋中 3 红 2 白，不放回取两次，求第二次取到红的概率。

**解** 全概率：$\frac{3}{5}\cdot\frac{2}{4}+\frac{2}{5}\cdot\frac{3}{4}=\frac{3}{5}$（与第一次无关）。

## 易错点
- 把 $P(B|A)$ 与 $P(A|B)$ 混为一谈。
- 无放回问题按有放回算。
- 链式乘法时后一项的条件写错（应累积前面所有条件）。
