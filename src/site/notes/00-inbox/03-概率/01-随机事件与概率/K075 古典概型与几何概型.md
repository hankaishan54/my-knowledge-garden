# K075 古典概型与几何概型

> 概率 · 随机事件与概率 · 真题 5 题（数一 4 / 数二 0 / 数三 1）

## 核心结论
- 古典概型：样本点有限且等可能，$P(A)=\dfrac{k}{n}$（有利数 / 总数）。
- 计数工具：排列 $A_n^k=\frac{n!}{(n-k)!}$、组合 $C_n^k$、分组问题要除以组数的阶乘。
- 几何概型：$P=\dfrac{\text{有利区域测度}}{\text{总区域测度}}$（长度、面积、体积）。
- "至少"类问题用对立事件：$P(\text{至少一个})=1-P(\text{一个都没有})$。
- 抽样：有放回用二项/乘法，无放回用组合或超几何。

## 关键公式
$$P(A)=\frac{k}{n}\ (\text{古典}),\qquad P(A)=\frac{m(D)}{m(\Omega)}\ (\text{几何})$$

## 典型例题
**例** 从 $1,2,\dots,9$ 中任取两数，求两数之和为偶数的概率。

**解** 总取法 $C_9^2=36$。和为偶数须同奇或同偶：$C_5^2+C_4^2=10+6=16$，故 $P=\frac{16}{36}=\frac{4}{9}$。

## 易错点
- 组合与排列混用（不分顺序却用排列）。
- 分组问题忘记除以重复组数。
- 几何概型中把"测度"选错（如用长度代替面积）。
