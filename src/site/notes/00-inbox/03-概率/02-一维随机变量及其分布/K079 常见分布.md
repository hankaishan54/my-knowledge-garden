# K079 常见分布

> 概率 · 一维随机变量及其分布 · 真题 71 题（数一 24 / 数二 0 / 数三 47）

## 核心结论
- 二项分布 $B(n,p)$：$P(X=k)=C_n^k p^k(1-p)^{n-k}$，$EX=np$，$DX=np(1-p)$。
- 泊松分布 $P(\lambda)$：$P(X=k)=\frac{\lambda^k}{k!}\mathrm{e}^{-\lambda}$，$EX=DX=\lambda$。
- 均匀分布 $U(a,b)$：$f=\frac{1}{b-a}$，$EX=\frac{a+b}{2}$，$DX=\frac{(b-a)^{2}}{12}$。
- 指数分布 $E(\lambda)$：$f=\lambda\mathrm{e}^{-\lambda x}\ (x>0)$，$EX=\frac{1}{\lambda}$，$DX=\frac{1}{\lambda^{2}}$，无记忆性。
- 正态分布 $N(\mu,\sigma^{2})$：标准化 $Z=\frac{X-\mu}{\sigma}\sim N(0,1)$，查表。
- 贝塔分布等连续型分布不在考研大纲内，不展开。

## 关键公式
$$Z=\frac{X-\mu}{\sigma}\sim N(0,1),\qquad P(X\le x)=\Phi\!\left(\frac{x-\mu}{\sigma}\right)$$

## 典型例题
**例** 设 $X\sim N(2,4)$，求 $P(X<4)$。

**解** $\sigma=2$，$P(X<4)=\Phi\!\left(\frac{4-2}{2}\right)=\Phi(1)\approx0.8413$。

## 易错点
- 正态记号 $N(\mu,\sigma^{2})$ 中第二个参数是方差，代成标准差。
- 指数分布与泊松分布的参数关系记混。
- 查表时忘记用 $\Phi(-x)=1-\Phi(x)$。
