# K084 数学期望

> 概率 · 数字特征 · 真题 28 题（数一 16 / 数二 0 / 数三 12）

## 核心结论
- 定义：离散 $EX=\sum x_ip_i$；连续 $EX=\int_{-\infty}^{+\infty}xf(x)\mathrm{d}x$（要求绝对收敛）。
- 随机变量函数的期望：$E[g(X)]=\int g(x)f(x)\mathrm{d}x$，**不必先求 $g(X)$ 的分布**。
- 线性性：$E(aX+bY+c)=aEX+bEY+c$，**不要求独立**。
- 独立时才有 $E(XY)=EX\cdot EY$（反之不成立）。
- 常见：$E(\text{二项})=np$，$E(\text{泊松})=\lambda$，$E(\text{指数})=\frac{1}{\lambda}$，$E(N(\mu,\sigma^{2}))=\mu$。

## 关键公式
$$E[g(X)]=\int_{-\infty}^{+\infty}g(x)f(x)\,\mathrm{d}x,\qquad E(XY)=EX\cdot EY\ (\text{独立})$$

## 典型例题
**例** 设 $X\sim U(0,1)$，求 $E(\mathrm{e}^{X})$。

**解** $E(\mathrm{e}^{X})=\int_0^1\mathrm{e}^{x}\mathrm{d}x=\mathrm{e}-1$。

## 易错点
- 不独立也用 $E(XY)=EX\cdot EY$。
- 求 $E(X^{2})$ 时用 $E(X)^{2}$（两者差一个方差）。
- 连续型期望积分区间与支撑集不符。
