# 考研数学知识点总览（MOC）

> 按考研数学大纲拆成 92 个知识点（其中 K051 题库中暂无真题），一个知识点一篇笔记 + 一份逐题真题集。
> 数据源：`99-fixed` 校对版原卷的逐题 `#考点/` 标签（1987—2026，共 2847 题，全部有归属）。
> 解析构成：2631 题用原卷解析（标「（原卷解析）」）；165 题（1987—1996 年数三试卷Ⅴ 卷）原卷解析缺失，已由本库补写（标「（补写解析）」，按题干独立推导）。全库每题都有解析，无「暂缺」。

## 怎么用

- 按板块 → 章节 → 知识点逐级点开；`Kxxx …` 是知识点正文，`Kxxx … · 真题集` 是按该知识点汇齐的题干与解析
- 每道真题只归一个知识点；`#考点/xxx` 标签可再回查 `99-fixed` 原卷
- frontmatter 的 `掌握度` 自己改成 0—5，下面的查询会按掌握度升序排（先练最生的）

```dataview
TABLE 题量, 掌握度, 章节
FROM #知识点
SORT 掌握度 ASC, 题量 DESC
LIMIT 30
```
