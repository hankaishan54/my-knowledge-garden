# K042 斯托克斯公式与场论

> 高数 · 多元函数积分学 · 真题 11 题（数一 11 / 数二 0 / 数三 0）

## 核心结论
- 斯托克斯公式：$\oint_\Gamma P\mathrm{d}x+Q\mathrm{d}y+R\mathrm{d}z=\iint_\Sigma\begin{vmatrix}\mathrm{d}y\mathrm{d}z&\mathrm{d}z\mathrm{d}x&\mathrm{d}x\mathrm{d}y\\ \frac{\partial}{\partial x}&\frac{\partial}{\partial y}&\frac{\partial}{\partial z}\\ P&Q&R\end{vmatrix}$，$\Sigma$ 以 $\Gamma$ 为边界，方向符合右手法则。
- 环流量 $=\oint_\Gamma \vec{F}\cdot\mathrm{d}\vec{r}$；旋度 $\operatorname{rot}\vec{F}=\nabla\times\vec{F}$。
- 散度 $\operatorname{div}\vec{F}=P_x+Q_y+R_z$，是高斯公式的核。
- 场论题常问"是否为保守场"：$\operatorname{rot}\vec{F}=0$ 且在单连通域内 $\Rightarrow$ 存在势函数。

## 关键公式
$$\operatorname{rot}\vec{F}=\left(R_y-Q_z,\ P_z-R_x,\ Q_x-P_y\right),\qquad \operatorname{div}\vec{F}=P_x+Q_y+R_z$$

## 典型例题
**例** 计算 $\oint_\Gamma y\,\mathrm{d}x+z\,\mathrm{d}y+x\,\mathrm{d}z$，$\Gamma$ 为平面 $x+y+z=1$ 与三坐标面围成三角形的边界（从 $z$ 轴正向看逆时针）。

**解** 取 $\Sigma$ 为该三角形上侧，$\operatorname{rot}\vec{F}=(-1,-1,-1)$，与 $\vec{n}=\frac{1}{\sqrt3}(1,1,1)$ 点积为 $-\sqrt3$，面积 $\frac{\sqrt3}{2}$，故积分 $=-\frac{3}{2}$。

## 易错点
- 行列式展开时符号顺序错（应为 $R_y-Q_z$ 等）。
- 曲面方向与曲线方向不满足右手法则。
- 把旋度与散度公式记混。
