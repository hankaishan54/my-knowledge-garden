# K036 三重积分的计算

> 高数 · 多元函数积分学 · 真题 8 题（数一 8 / 数二 0 / 数三 0）

## 核心结论
- 直角坐标"先一后二"（投影法）：$\displaystyle\iiint_\Omega f\,\mathrm{d}V=\iint_{D_{xy}}\mathrm{d}\sigma\int_{z_1(x,y)}^{z_2(x,y)}f\,\mathrm{d}z$。
- 柱坐标：$\mathrm{d}V=r\,\mathrm{d}r\,\mathrm{d}\theta\,\mathrm{d}z$，适用于绕 $z$ 轴的旋转体、含 $x^{2}+y^{2}$ 的被积函数。
- 球坐标：$\mathrm{d}V=\rho^{2}\sin\varphi\,\mathrm{d}\rho\,\mathrm{d}\varphi\,\mathrm{d}\theta$，适用于球体、锥体、含 $x^{2}+y^{2}+z^{2}$ 的被积函数。
- "先二后一"（截面法）：被积函数只含 $z$ 时，先算 $z$ 处截面积 $S(z)$，再 $\int f(z)S(z)\mathrm{d}z$。

## 关键公式
$$\mathrm{d}V=r\,\mathrm{d}r\mathrm{d}\theta\mathrm{d}z\ (\text{柱});\qquad \mathrm{d}V=\rho^{2}\sin\varphi\,\mathrm{d}\rho\mathrm{d}\varphi\mathrm{d}\theta\ (\text{球})$$

## 典型例题
**例** 计算 $\displaystyle\iiint_\Omega z\,\mathrm{d}V$，$\Omega$ 为 $x^{2}+y^{2}+z^{2}\le1,\ z\ge0$。

**解** 截面法：$z$ 处截面为半径 $\sqrt{1-z^{2}}$ 的圆，$S(z)=\pi(1-z^{2})$，故 $\int_0^1 z\pi(1-z^{2})\mathrm{d}z=\frac{\pi}{4}$。

## 易错点
- 柱坐标漏 $r$，球坐标漏 $\rho^{2}\sin\varphi$。
- 球坐标中 $\varphi$ 与 $\theta$ 的取值范围写反（$\varphi$ 是与 $z$ 轴夹角，$0\le\varphi\le\pi$）。
- 用截面法时把截面积算成"面积元素"。
