# K051 曲面与空间曲线

> 高数 · 向量代数与空间解析几何 · 真题 0 题（题库中暂无该知识点的真题，本文只保留知识要点）

## 核心结论
- 常见曲面方程：球面 $x^{2}+y^{2}+z^{2}=R^{2}$；柱面（缺一个变量）；旋转抛物面 $z=x^{2}+y^{2}$；圆锥面 $z^{2}=x^{2}+y^{2}$。
- 旋转曲面：曲线 $f(y,z)=0$ 绕 $z$ 轴旋转，得 $f(\pm\sqrt{x^{2}+y^{2}},z)=0$（把 $y$ 换成 $\pm\sqrt{x^{2}+y^{2}}$）。
- 空间曲线的一般式是两个曲面方程联立；参数式为 $x=x(t),y=y(t),z=z(t)$。
- 投影到 $xOy$ 面：从两个方程中消去 $z$。

## 关键公式
$$f(y,z)=0\ \text{绕}\ z\ \text{轴}\Rightarrow f\!\left(\pm\sqrt{x^2+y^2},z\right)=0$$

## 典型例题
**例** 求 $yOz$ 面上曲线 $y^{2}=2z$ 绕 $z$ 轴旋转所得曲面方程。

**解** 把 $y$ 换成 $\pm\sqrt{x^{2}+y^{2}}$：$x^{2}+y^{2}=2z$，为旋转抛物面。

## 易错点
- 旋转时替换错变量（绕哪个轴转，就把另一个变量替换成平方和开根）。
- 求投影柱面时没消去 $z$，得到的仍是空间曲线。
- 把柱面方程误认为平面。
