# K049 向量运算

> 高数 · 向量代数与空间解析几何 · 真题 1 题（数一 1 / 数二 0 / 数三 0）

## 核心结论
- 数量积：$\vec{a}\cdot\vec{b}=|\vec{a}||\vec{b}|\cos\theta=a_1b_1+a_2b_2+a_3b_3$；$\vec{a}\perp\vec{b}\iff\vec{a}\cdot\vec{b}=0$。
- 向量积：$\vec{a}\times\vec{b}$ 是向量，$|\vec{a}\times\vec{b}|=|\vec{a}||\vec{b}|\sin\theta$ 等于平行四边形面积；$\vec{a}\parallel\vec{b}\iff\vec{a}\times\vec{b}=\vec{0}$。
- 混合积：$(\vec{a}\times\vec{b})\cdot\vec{c}$ 的绝对值等于平行六面体体积；三向量共面 $\iff$ 混合积为 $0$。
- 方向余弦：$\cos\alpha=\frac{a_1}{|\vec{a}|}$ 等，满足 $\cos^{2}\alpha+\cos^{2}\beta+\cos^{2}\gamma=1$。

## 关键公式
$$\vec{a}\times\vec{b}=\begin{vmatrix}\vec{i}&\vec{j}&\vec{k}\\ a_1&a_2&a_3\\ b_1&b_2&b_3\end{vmatrix},\qquad V=|(\vec{a}\times\vec{b})\cdot\vec{c}|$$

## 典型例题
**例** 求以 $A(1,0,0),B(0,1,0),C(0,0,1)$ 为顶点的三角形面积。

**解** $\overrightarrow{AB}=(-1,1,0)$，$\overrightarrow{AC}=(-1,0,1)$，叉乘得 $(1,1,1)$，面积 $=\frac{1}{2}\sqrt3=\frac{\sqrt3}{2}$。

## 易错点
- 叉乘的行列式顺序写反（$\vec{a}\times\vec{b}=-\vec{b}\times\vec{a}$）。
- 三角形面积忘记除以 $2$。
- 用数量积判垂直时算成平行。
